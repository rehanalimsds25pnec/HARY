
# Haikus for Codespaces

This is a quick node project template for demoing Codespaces. It is based on the [Azure node sample](https://github.com/Azure-Samples/nodejs-docs-hello-world). It's great!!!

Point your browser to [Quickstart for GitHub Codespaces](https://docs.github.com/en/codespaces/getting-started/quickstart) for a tour of using Codespaces with this repo.

## Pine Script Trading Indicator

This repository also includes a Pine Script trading indicator for TradingView. See [`PINE_SCRIPT_GUIDE.md`](PINE_SCRIPT_GUIDE.md) for detailed documentation on how to use the indicator.

- **File**: `trading_indicator.pine`
- **Purpose**: Technical analysis indicator combining Moving Average and RSI for trading signals
- **Platform**: TradingView
